# Tales for Nights 🌙

**Tales for Nights** is a beautifully crafted, modern web application designed for storytelling, poetry, and raw thoughts. It provides a serene, premium reading experience with a polished glassmorphic interface, smooth animations, and seamless dark/light mode support.

## 📖 About the Project

**Tales for Nights** serves as a digital sanctuary for creative writing. The application is thoughtfully divided into distinct sections, each tailored to different forms of expression:

- **Tales**: Fully fleshed-out stories and narratives, complete with rich text, cover art, and integrated audio playback for an immersive storytelling experience.
- **RAWs**: Unfiltered thoughts, quick ideas, and short snippets. Features pinning, tagging, and quick search capabilities.
- **Charms**: Short poetic snippets and lyrical verses.
- **Lyrics**: A dedicated space for song lyrics.

The project also features a secure **Admin Dashboard**, allowing authorized users to seamlessly create, edit, manage, and curate content directly from the interface using advanced rich-text editors and intuitive form controls.

### ✨ Key Features
- **Premium Glassmorphic UI**: A highly polished, modern aesthetic with translucent frosted glass effects, subtle glows, and deep attention to design details.
- **Fluid Animations**: Powered by Framer Motion, featuring smooth page transitions, micro-interactions, and beautiful wave skeleton loaders for a native app-like feel.
- **Dark & Light Mode**: First-class support for dynamic theming, ensuring a comfortable and gorgeous reading experience at any hour of the day.
- **Rich Media Support**: Integrated audio players for narrated tales and full image support for cover art.
- **Optimized Performance**: Utilizes TanStack Query (React Query) for highly optimized data fetching, caching, and mutations, alongside Redux Toolkit for global state management.
- **Fully Responsive**: Flawlessly adapts to any screen size, from mobile devices to large desktop monitors.

## 🛠️ Technology Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, Turbopack)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Components & Icons**: Material UI (MUI) & Custom styled components
- **Animations**: Framer Motion
- **State Management**: Redux Toolkit & React-Redux
- **Data Fetching & Caching**: TanStack Query (React Query)
- **Database / Backend**: Custom Next.js API routes with MongoDB

## 🚀 Getting Started

First, install the dependencies (we recommend using `pnpm`):

```bash
pnpm install
```

Then, run the development server:

```bash
pnpm dev
# or npm run dev, yarn dev, bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
